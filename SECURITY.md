# Security

identity-gen is one HTML page that runs in your browser. It sends nothing by default and keeps its state in the browser's local storage. Two opt-in features make requests: the Illustrated avatar styles load DiceBear from jsDelivr, and Photo mode fetches an image from the source you pick.

Report a security problem through GitHub's private vulnerability reporting (Security tab, "Report a vulnerability"), not a public issue. I aim to reply within a week.

Only the latest version, the one served at https://real-fruit-snacks.github.io/identity-gen/, is supported.
